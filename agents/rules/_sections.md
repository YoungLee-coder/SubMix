# Sections

本文件定义规则分类、排序和影响级别。
括号中的 ID 是规则文件名前缀。

---

## 1. Architecture (architecture)

**Impact:** CRITICAL
**Description:** 项目分层、Server/Client 边界、数据流、组件职责划分等架构约定。

## 2. Security (security)

**Impact:** CRITICAL
**Description:** CORS、频率限制、请求校验、输入防护等安全相关的规则。

## 3. Code Quality (quality)

**Impact:** HIGH
**Description:** TypeScript 严格模式、hooks 依赖数组、命名、最小化 diff 等代码质量标准。

## 4. API Design (api)

**Impact:** HIGH
**Description:** API 路由设计、请求校验、响应格式、错误处理规则。

## 5. Performance (performance)

**Impact:** MEDIUM
**Description:** 性能优化、缓存策略、避免不必要的重新渲染。

## 6. UI / Frontend (ui)

**Impact:** MEDIUM
**Description:** 组件库约定、样式规范、状态管理模式、无障碍标准。

## 7. Testing (testing)

**Impact:** MEDIUM
**Description:** Vitest 测试覆盖、模拟策略、测试命名规范。

## 8. Patterns (patterns)

**Impact:** LOW
**Description:** 设计模式、协议解析流水线、配置生成模式等通用模式。

## 9. Reference (reference)

**Impact:** LOW
**Description:** 关键文件位置、验证清单、本地开发指南等信息查询。
